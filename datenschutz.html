Datenschutzerklärung – Hermes Zugriff

Verantwortlicher: Simon Monath (Kontakt über das GitHub-Profil simonmonath95-hub)

Zweck

„Hermes Zugriff" ist eine private Anwendung. Sie greift ausschließlich auf das Google-Konto des Betreibers zu, um dessen E-Mails (Gmail), Kalender, Drive, Docs, Sheets und Kontakte durch einen selbst betriebenen KI-Assistenten zu lesen, zu ordnen und zu bearbeiten.

Welche Daten werden verarbeitet?

Nur die Daten des Betreiber-Kontos, auf die der Betreiber über die Google-Anmeldung ausdrücklich zugegriffen hat. Der Zugriff erfolgt über die offiziellen Google-APIs mit einem Anmelde-Token, das auf dem eigenen Server des Betreibers gespeichert ist.

Weitergabe und Speicherung

Die Daten werden nicht verkauft, nicht an Dritte weitergegeben und nicht für Werbung verwendet. Sie werden nur auf dem eigenen Server des Betreibers verarbeitet. Für die Textverarbeitung können einzelne Inhalte an einen KI-Modell-Anbieter (OpenRouter) gesendet werden, ausschließlich zur Ausführung der vom Betreiber angeforderten Aufgaben.

Google-Nutzerdaten

Die Nutzung von Informationen, die von Google-APIs stammen, entspricht der Google API Services User Data Policy, einschließlich der Anforderungen zur eingeschränkten Nutzung (Limited Use).

Widerruf und Löschung

Der Zugriff kann jederzeit unter myaccount.google.com/permissions widerrufen werden. Gespeicherte Anmelde-Token werden dann gelöscht.
